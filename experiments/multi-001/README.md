# MULTI-001

This experiment searches for naturally occurring autonomous-customer
onboarding failures across unrelated real developer products.

It is a discovery experiment.

No defect is planted.

No repair is selected in advance.

The experiment must preserve negative results.

The key sequence is:

Observe
-> independently verify
-> classify
-> localise
-> freeze diagnosis
-> minimal repair
-> fresh replay
-> measure AFCR

Initial candidates:

1. Postmark
2. Stripe
3. Clerk

No vendor execution has occurred merely by creating this experiment.
